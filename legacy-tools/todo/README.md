# 待办清单 (Todo)

极简风格的待办管理工具。Linear/Notion 设计语言，纯 CSS + Web Animations API 动画。

## 功能

- 任务：新增 / 完成 / 删除 / 双击编辑 / 拖拽重排
- 优先级：无 / 低 / 中 / 高（颜色圆点）
- 截止日期：今天 / 明天 / 过期 高亮
- 分组：自定义 + 默认「收件箱 / 今日 / 个人」
- 子任务：勾选 / 文本 / 删除
- 标签：`#` 自动识别，多标签
- 备注：极简 Markdown 解析（标题 / 粗斜 / 代码 / 列表 / 引用 / 复选框）
- 主题：亮 / 暗 双主题
- 搜索 + 过滤：全部 / 进行中 / 已完成
- 云同步：登录后自动同步（debounce 1.5s + 失败重试 1s/3s/8s）
- 本地草稿导入：登录后弹对话框询问

## API

`/api/todos`
- `GET` — 读取当前用户的 JSON
- `PUT` — 全量覆盖（最大 256 KB）
- `DELETE` — 清空

详见 `API/routes/todos.js`。

## 快速添加：自动识别时间

快速添加框提交时会从标题里识别日期 / 时间点并填到 `dueDate` / `dueTime`，识别到的片段会从标题移除。

### 日期

| 类型 | 示例 |
|------|------|
| 中文自然语言 | 今天 / 明天 / 后天 / 大后天 / 周X / 本周X / 下周X / 周末 / 下周末 / 月底 / 下月底 |
| 相对偏移 | `3天后` / `2周后` / `1个月后` / `3月之后`（必须带「后」） |
| 数字日期 | `1/5` / `1-5` / `1月5日`（同年，已过则推至次年；分隔符不支持 `.`，避免与版本号冲突） |
| 绝对日期 | `2026-09-04` / `2026/9/4` / `2026.9.4` / `2026年9月4日` |

### 时间点

| 类型 | 示例 |
|------|------|
| 24h HH:MM | `15:30` / `9:00` / `23:59` |
| 中文时段 + N点 / N点半 / N点MM分 / N:MM | `下午3点` / `上午10点半` / `晚上9点` / `中午12点` / `下午3:30` / `下午3点30分` / `凌晨1点` / `夜里11点` |
| 相对 now | `一分钟后` / `3分钟后` / `半小时后` / `1小时后` / `两小时后` / `10小时后`（跨日） |

时段词支持：`上午` / `早上` / `清晨` / `凌晨` / `中午` / `下午` / `晚上` / `夜里`。**裸 `3点` 不会被识别**（避免歧义），必须带时段或写成 `15:30`。

相对偏移支持阿拉伯数字（`3` / `10`）和中文数字（一/两/三/…/十/十一/…/九十九）。`半小时后` 视为 30 分钟。

### 组合示例

| 输入 | 标题 | DDL | 时间 |
|------|------|-----|------|
| `明天下午3点 开会` | 开会 | 明天 | 15:00 |
| `今天 15:30 报告` | 报告 | 今天 | 15:30 |
| `3天后 10:00 提交` | 提交 | 3 天后 | 10:00 |
| `下周三 上午9点 体检` | 体检 | 下周三 | 09:00 |
| `一分钟后 喝水` | 喝水 | 今天 | now+1min |
| `10小时后 吃药` | 吃药 | 明天（若跨日） | now+10h |

实现细节见 `js/datetime.js`（`parseDateExpression(text, today)` / `parseTimeExpression(text)`），测试见 `tests/todo-datetime.test.mjs`。

## 浏览器通知提醒

任务可设置浏览器 Notification 提醒（需要页面打开时有效）。三个相关字段：

| 字段 | 来源 | 含义 |
|------|------|------|
| `dueTime` | 任务 | 显式时间点（HH:MM）。空时按全局「默认时间」算。 |
| `reminderOffset` | 任务 | 该任务提前多少分钟提醒。空时按全局「默认提前量」算。 |
| 全局「默认时间」/「默认提前量」 | ui_config（云端） | 没有上面两个字段时的兜底值 |

### 全局默认值

在 `https://api.oscarstudio.cn/settings.html` 的「待办提醒默认值」卡里设置：

- **默认时间** — 没有 `dueTime` 的任务按这天的这时刻计算提醒点（默认 09:00）
- **默认提前量** — 有 `dueTime` 的任务提前多少分钟提醒（默认 30）

跨子域同步：todo 应用启动时通过 `GET /api/ui` 拉到本地 localStorage 缓存。

### 触发逻辑

```
triggerAt = (dueDate + (dueTime ?? 默认时间)) - (reminderOffset ?? 默认提前量) 分钟
```

触发时调浏览器 `Notification` 显示任务标题 + 截止时间，并把 `notifiedAt` 写入任务防止重复。**距 dueAt 超过 24h 就不再补提醒**（避免每次开页都弹历史逾期）。

### 启用

首次使用需点击右上角 🔕 铃铛申请 Notification 权限。granted 后铃铛变 🔔。权限被拒绝时只能在浏览器站点设置中开启。

实现细节见 `js/reminder.js`（`initReminder({ getState, getPrefs, markNotified })`）。
